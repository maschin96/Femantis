# Projektstand Femantis Desktop

Stand: 19.10.2026. **Femantis Desktop** ist der Produktname (Version `0.2.0`); das private GitHub-Repository heißt [maschin96/Firmantis](https://github.com/maschin96/Firmantis). `main` ist der Integrationsbranch. Die numerische [FEM-Toolbox](https://github.com/maschin96/FEM-Toolbox) ist eine getrennte, auf Version 1.4.0 und Commit `baae07f088a87ce6e256af3c5855a3b110d0f17a` fixierte Abhängigkeit. Die lokalen D0–D7-Pakete im [UI-Plan](ELECTRON_UI_PLAN.md) sind Planungskennungen, keine GitHub-Milestones oder Issue-Nummern. [Erster Viewer-Schnitt](IMPLEMENTATION.md) und [Modellierungsschnitt](MODELLING_IMPLEMENTATION.md) dokumentieren ihre jeweiligen Prüfungen vom 13.10.2026; deren damalige Testzahlen dürfen nicht als aktuelle CI- oder Releaseabnahme gelesen werden.

| Paket | Implementierter Umfang und aktuelles Gate |
|---|---|
| D0 – Vertragsprobe | Tet4-/Tet10-Referenznetze, Original-ID-/Gruppenvertrag und [Backend-Baseline](evidence/backend-baseline.json) sind lokal dokumentiert. Die Baseline misst keine Viewer-FPS. |
| D1 – Desktopgerüst | Electron, React, isoliertes Preload-API, validierte Main-Aktionen, Python-Adapter und portable Viewerprojekte sind implementiert. Ein praktisch geprüftes Installationspaket bzw. eine gebündelte Runtime fehlen; siehe [#10](https://github.com/maschin96/Firmantis/issues/10) und [#11](https://github.com/maschin96/Firmantis/issues/11). |
| D2 – 3D-Viewer | Tet4/Tet10, Außenhaut, Gruppen, Auswahl und Original-IDs sind implementiert und unter macOS/Apple Silicon getestet. Das Leistungsziel für 100.000 Tet4-Zellen ist offen ([#8](https://github.com/maschin96/Firmantis/issues/8)); quadratisch korrekte Tet10-Felder sind offen ([#9](https://github.com/maschin96/Firmantis/issues/9)). |
| D3 – Modelleditor | Stationäre Wärme, lineare Elastizität und Elektrostatik mit Model-Schema 1, Formularen, JSON-Editor und TOML-Roundtrip sind implementiert. Eingabesicherheit und bewusster Modellneustart wurden über [PR #16](https://github.com/maschin96/Firmantis/pull/16) und [PR #17](https://github.com/maschin96/Firmantis/pull/17) in `main` integriert; strukturierte Toolbox-Diagnosen bis zum Editorfeld sind für [#6](https://github.com/maschin96/Firmantis/issues/6) lokal verifiziert und noch nicht in `main` integriert ([Nachweis](ISSUE_6_VERIFICATION.md)). |
| D4 – Jobs und Ergebnisse | Stationäre Läufe, Abbruch, Rohfelder, Bilanzen, Verformungsansicht und Schema-2-Speicherung sind implementiert. Die Korrekturen für kleine Farbunterschiede ([PR #18](https://github.com/maschin96/Firmantis/pull/18), [#3](https://github.com/maschin96/Firmantis/issues/3)) und verbindliche Ergebniszuordnung ([PR #19](https://github.com/maschin96/Firmantis/pull/19), [#1](https://github.com/maschin96/Firmantis/issues/1)) sind in `main` integriert. Dauerhafte Laufverwaltung/Cachebegrenzung bleibt [#7](https://github.com/maschin96/Firmantis/issues/7). |

D5–D7 sind keine fertiggestellten Produktbereiche. Die nächsten Verträge und Schnitte sind [gekoppelte Physiken #14](https://github.com/maschin96/Firmantis/issues/14), [CAD/Meshing #13](https://github.com/maschin96/Firmantis/issues/13) und [Zeit-/Frequenz-/Modenserien #15](https://github.com/maschin96/Firmantis/issues/15). macOS-Auslieferung [#10](https://github.com/maschin96/Firmantis/issues/10) sowie Windows-/Linux-Prüfung [#11](https://github.com/maschin96/Firmantis/issues/11) sind eigene Gates. Keine dieser Erweiterungen wird durch den jetzigen stationären Solver- oder Viewerumfang impliziert.

Der Workflow für automatische Prüfungen ist über [PR #20](https://github.com/maschin96/Firmantis/pull/20) in `main` integriert; [#5](https://github.com/maschin96/Firmantis/issues/5) bleibt offen. Auch der `main`-Lauf vom 14.10.2026 startete keinen Runner. Der erste GitHub-Lauf startete wegen einer Billing-/Ausgabenlimitsperre keinen Runner; außerdem fehlt noch das auf die private Toolbox beschränkte Lesesecret. Damit liegen am Stichtag weder grüne PR-/`main`-CI noch ein Desktop-Runnertest auf GitHub vor. Branch Protection ist nicht nachgewiesen. Lokale Prüfergebnisse der einzelnen PRs stehen in deren Beschreibungen und sind nicht automatisch auf eine gemeinsame Integration übertragbar.

Reproduzierbare lokale Befehle stehen in der [README](../README.md): `npm ci`, `npm run setup:backend`, `npm test`, `npm run test:backend`, `npm run typecheck`, `npm run build`, `npm run test:desktop` und `npm run benchmark` (bei Topologie-/Binärleistungsänderungen). Die `.femantis.json`-Datei und ihr `.files`-Ordner bilden gemeinsam ein portables Projekt. Praktische Nachweise außerhalb macOS/Apple Silicon liegen noch nicht vor.
